# 역사 퀴즈 데이터 — VSCode 인계용

## 폴더 구성
```
history-quiz-data/
├── questions.json      ← 문제 30개 전체 (질문/정답/힌트/이미지 경로)
├── images/              ← 힌트에 쓰이는 사진 8장
└── README.md            ← 이 파일
```

## Claude Code에게 넘길 때 이렇게 말하면 돼요

> "questions.json에 문제 30개가 정리되어 있어. 확정된 디자인(첨부한 참가자 화면 프로토타입 HTML)을 그대로 유지하면서, 이 데이터를 읽어서 문제를 보여주는 구조로 만들어줘.
> - hint_type이 'image'인 문제는 힌트 카드에 images/ 폴더의 이미지를 보여줘
> - invalid_answers가 있는 문제는 출제자 화면에 '이 답은 오답 처리' 안내를 표시해줘 (예: 7번 문제는 '태조'라고 답해도 오답)
> - 19번은 힌트가 수식이라 이미지 없이 텍스트 그대로 보여주면 돼"

## 주의할 점
- 7번 문제(왕건): '태조'는 시호라서 오답 처리하기로 함. 출제자가 헷갈리지 않도록 관리자 화면에 눈에 띄게 표시해달라고 요청하면 좋음.
- 19번 문제: 힌트가 간단한 수식 퍼즐(A=1, B=A+8, C=B−5, D=C+1 → ABCD)이라 이미지가 필요 없음.
- 29번 문제: 원래 세트에서 교체된 문제. "사라예보 사건"이 정답.
